# 📊 Telecom Customer Churn Prediction

## 📌 Project Overview
Telecom Customer Churn Prediction is a machine learning project designed to predict whether a customer is likely to discontinue their telecom services. The project uses customer data to identify potential churn and help telecom companies make data-driven decisions to improve customer retention.

A Logistic Regression model is implemented to classify customers based on their likelihood of churning, with an interactive Streamlit dashboard for visualizing insights and generating predictions.

## 🎯 Objectives
- Analyze customer data to identify churn patterns.
- Build a machine learning model to predict customer churn.
- Identify customers who are likely to leave the service.
- Provide an interactive dashboard for customer insights and predictions.

## 🛠️ Technologies Used
- **Python** – Data processing and model development
- **Pandas** – Data manipulation and analysis
- **Scikit-learn** – Machine learning and model training
- **Streamlit** – Interactive dashboard development
- **Logistic Regression** – Customer churn classification

## ⚙️ Key Features
- Customer churn prediction using Logistic Regression.
- Approximately **89% test accuracy**.
- Interactive Streamlit dashboard.
- KPI-based visualization of customer data.
- Real-time customer churn predictions.
- Data-driven insights to support customer retention strategies.

## 🧠 Machine Learning Model
The project uses Logistic Regression, a supervised machine learning classification algorithm.

The model learns patterns from historical customer data and predicts whether a customer is likely to:
- **Churn** – Discontinue the telecom service.
- **Not Churn** – Continue using the service.

The model achieved approximately 89% accuracy on the test dataset.
